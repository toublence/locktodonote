# 1.2.3 개선 의사결정표

실사용 데이터가 아직 없다. 아래는 판단 규칙이며 이번 작업에서 효과나 원인을 입증한 결과가 아니다. 소수 사용자에서 단발성 비율 변화를 과장하지 않는다. 분모·기간·절대 수·관측 손실·버전·코호트·무료/Pro를 함께 제시한다.

| 데이터로 확인할 문제 | 가능한 원인(가설) | 1.2.3 검토·추가 확인 |
| --- | --- | --- |
| 신규 작성 시작 대비 저장이 낮음 | 설명/키보드/저장 발견성, 단순 구경, 앱 중단 | 시간 구간과 실패/명시 취소/미관측 분리 후 실제 첫 작성 과제 재현 |
| 시작 후 명시 취소·유형 변경이 반복 | 입력 유형 혼동, 기존 습관, 잘못된 진입 | 기존 인라인 흐름의 문구·기본값부터 검토. 새 작성창을 먼저 만들지 않음 |
| 첫 저장은 되지만 표시 요청/성공이 낮음 | 설정 진입 불명확, 권한/OS 제한, 자동 시도 누락 | request_id별 실패 코드와 시작 시점 재현. 저장과 실제 시청을 합치지 않음 |
| 기록용 메모 뒤 템플릿 재변경이 빈번 | 빠른 교체를 기대했음, 원래 다른 표시 목적 | 토글/유형 구분 사용자 과제로 확인. 시간상 인접만으로 실수라고 단정하지 않음 |
| 후보 초과와 선택 변경이 반복 | 범위 선택 유지 부담, 행 상한, 발견성 | 기본 무료/Pro 범위를 나눠 기존 선택으로 과제를 수행. 부족이 재현될 때만 현재 범위 내 최소 순서 조정 검토 |
| 선택 범위 밖 새 항목이 누적 | 규칙 개별 선택 계약을 이해하지 못함 | 기존 규칙 안내/진입 개선부터 검토. 자동 편입·전역 우선순위를 임의 추가하지 않음 |
| 반복·미리알림 사용자의 의미 있는 사용일이 많음 | 지속 가치, 원래 충성도가 높은 사용자의 선택 효과 | 신규/기존·관측 성숙도·유료 상태를 맞춰 비교하고 원래 성향의 영향을 분리 |
| Pro 미리보기 조작은 많지만 구매가 적음 | 가치 전달/가격/상품 로딩/결제 취소, 단순 탐색 | trigger별 시도·결과·실제 체험·기능을 나눠 본다. 즉시 가격/권리를 바꾸지 않음 |
| 구매 후 적용 실패·복구가 많음 | 사진/설정 저장 실패, Activity 권한, 목적 맥락 유실 | verified → application → display 결과 분리. 결제 성공과 목적 달성 실패를 함께 재현 |
| 앱 밖 완료는 많고 앱 실행은 적음 | 앱 밖 가치가 충분함, 일부 전송 지연 | 핵심 행동일·최종 저장률로 평가. 앱 실행을 늘리려 광고/제안을 되살리지 않음 |
| 광고 감소가 총수익 감소로 이어짐 | 앱 오픈 중단, 지역/유입/Pro 구성 변화 | ASC+AdMob 동일 30일 실수익과 사용성을 비교. 안전한 노출 구간 증명 전 광고 재개 금지 |
| 큐 지연·폐기·unresolved가 많음 | 장기간 앱 미실행, 기술 이벤트 누적, 오래된 대상/경합 | 제품 실패와 관측 손실을 구분. 백그라운드 트래픽으로 DAU를 만들지 않음 |

보고 형식: **확인 사실(기간/분모/수치) → 가능한 원인 → 반례/누락 → 개선 가설 → 최소 실험 → 성공/중단 기준**. 1.2.3에서도 l122_ 이름과 의미는 유지하고 릴리스 식별자만 해당 버전으로 갱신한다. 유지율 향상과 하루 $1 목표는 출시 이후 실제 자료로 평가한다.
