원본을 비공개 로컬 폴더에 백업했다. 사용자 카드/구성을 초기화하거나 앱을 삭제 설치하지 않았다. 업데이트 전후 카드 5개와 ID 집합 일치. 내용·체크리스트·완료·반복·표시 플래그 유지. 변한 필드는 targetDateTime/updatedAt뿐이며 날짜 이월과 갱신 시각에 해당한다. 기존 메모/사진/자동 전환 자료가 없었으므로 해당 기존 자료의 보존 검증을 했다고 주장하지 않는다. 기존 실제 유료 권리도 증거가 없어 미검증이다. 원본 내용·스크린샷은 보고서에 공개하지 않는다.

오늘 화면은 바깥 페이지와 안쪽 할 일 목록에 각각 ScrollView가 있다. 자동화가 바깥 화면만 스크롤하던 문제를 수정해 test02를 통과했다. 제품 UI나 기존 완료/삭제 알고리즘을 수정한 것은 아니다. QA 정리 시 UI 삭제가 남기는 내부 기록과 중단된 테스트 자료가 있어, 앱 프로세스가 없는 상태에서 **이번 실행으로 생성한 정확한 QA 카드 3개만** 현재 카드 파일에서 제거했다. 원본 5개는 그 시점의 값을 그대로 유지했으며 과거 백업 전체를 덮어쓰지 않았다. 재실행 후 다시 읽어 QA 0개와 기존 자료 보존을 확인했다.

Mac 여유 공간은 재시도 중 다시 소진됐다. xcodebuild가 exit 73으로 중단되고 파일 복사에서도 실제 No space left on device를 확인했다. 본 작업이 만든 재생성 가능한 모듈 캐시만 추가 정리해 최종 자료 비교·보고를 저장했다. 사용자 파일이나 다른 프로젝트 캐시는 삭제하지 않았다. 기기 지원 심볼 추출 경고도 남아 있다. 단순 기능 실패와 호스트 검증 환경 실패를 구분해야 한다.

원본 화면/카드 내용은 비공개 로컬 증거에만 두었다. 공개 보고서에는 성공 상태·개수·변경 필드만 보관한다. 앱 밖 완료의 최종 저장 증거는 evidence/ipad-live-activity-commit-2026-10-31.json, 최종 자료 비교는 evidence/ipad-upgrade-preservation-2026-10-31.json이다.
