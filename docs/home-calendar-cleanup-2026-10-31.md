# 오늘·캘린더 정리 및 Live Activity 자동 시작

- 오늘: ‘잠금화면 날짜 고정’ 안내와 바로 아래 ‘오늘 자동 표시’ 버튼 제거. 기존 날짜 선택/자동 전환 설정 자료는 변경하지 않음.
- 캘린더: Smart Repeat Pro 고급 반복 설정과 문장 자동 인식 토글 제거. 문장 인식은 설정의 기존 ON/OFF를 공유하며 입력 해석 결과 미리보기는 유지.
- Live Activity: 온보딩 완료·앱 첫 진입·앱 복귀 때 실행 중이 아니면 자동 시작. 이전 종료 플래그나 할 일/메모가 없는 달력 카드 때문에 시작이 차단되지 않게 함. 중복 시작 방지 적용. 실행 중인 활동은 다시 만들지 않으며 OS 권한 제한 및 실패 시 기존 안내/수동 재시도 유지.
- 기존 디자인·상품·유료 권리 및 반복 데이터 변경 없음.

검증: 수정 3개 파일 Swift 문법 파싱 통과. 이후 온보딩 완료 경로의 카드 유무 조건만 추가 제거했으며, 전체 빌드·실기기 재검증은 실행하지 않음.
