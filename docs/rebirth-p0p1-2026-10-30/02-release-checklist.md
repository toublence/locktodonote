# 출시 전 확인 및 남은 판단

2026-10-30. 개발·시뮬레이터 검증은 완료했고 App Store 배포는 하지 않았다. 아래 미검증 항목을 통과하기 전에는 출시 검증 완료로 처리하지 않는다.

## 반드시 실제 iPhone에서 확인

- [ ] 기존 설치본 백업 → 업데이트. 기존 구매자의 상품·영수증·구매 복원·구독/체험 만료를 실제 StoreKit 경로로 확인. 모의 Pro 결과와 구분한다.
- [ ] 작은 화면과 Dynamic Island 기기에서 Live Activity 시작·앱 종료·재부팅·권한 거부/복구·잠금화면 완료·앱 복귀 확인. 잠금화면 위젯 설치/액세서리 표면도 별도 확인한다.
- [ ] 단축어와 미리알림의 실제 외부 추가/완료/복귀, 연결 해제, 오프라인·권한 변경에서 기존 정책 확인. 단축어 공통 큐 정책은 유지했으나 실제 단축어 앱 왕복은 이번 검증의 완료 항목이 아니다.
- [ ] 자동 전환 시작/종료 시각, 자정, 표시 날짜 고정/오늘 복귀, 날짜 변경, N일 반복 다음 발생·완료 취소를 실제 시간 경과로 확인. 기존 엔진 재개발 없이 회귀 확인한다.
- [ ] 저장된 사진 구성 업그레이드·재적용, 활성 이미지 누락/디스크 부족에서 오류와 자료 보존 확인. 과거에 이미 삭제된 사진은 재선택이 필요할 수 있다.
- [ ] 모든 지원 언어의 새 문구·줄바꿈, 큰 글자·VoiceOver·토글 비활성 이유 확인.

## 실제 기존 사용자에게 확인

- [ ] 할 일 작성·완료와 표시 중 메모 편집이 전보다 번거롭지 않은지 같은 과제로 비교한다.
- [ ] 빠른 메모 교체 사용자가 토글 기본값을 이해하고 저장 1회로 끝내는지 확인한다.
- [ ] 유형 탭을 표시 전환으로 사용하던 사람이 기존 템플릿 선택을 발견하는지, 추가 선택이 실수 감소보다 더 큰 불편인지 확인한다.
- [ ] 미완료 30개에서 무료 기본 표시와 Pro 개별 선택을 분리해 평가한다. ‘선택 범위에 포함’과 ‘현재 표면에 실제 보임’을 혼동하지 않게 한다. 초과 수용량과 무료 기본 최신순의 밀림은 미해결이다.
- [ ] 구성 저장 후 복귀, 현재 규칙과 기본 표시 설정의 차이를 이해하는지 확인한다. 새 관리 UI나 우선순위를 먼저 추가하지 않는다.

## 무료·Pro 및 광고 판단

기존 상품·가격·복원·무료/Pro 경계를 바꾸지 않았다. 현재 앱 오픈 광고는 안전한 구간을 구분하지 못하므로 전체 차단했다. 기존 광고 SDK 설정과 구매자의 광고 제거 의미는 유지하지만 이 빌드에서는 무료 사용자에게도 해당 광고가 노출되지 않는다. 새 광고 형식을 추가하지 않았다. 자동 제안 차단으로 권리 만료 자체를 무효화하지 않는다.

동일한 30일 창에서 다음을 함께 판단한다. 아래 지표는 관측·분석해야 할 항목이며 이번 작업에서 모두 새로 계측했다고 주장하지 않는다.

| 지표 | 판단 목적 |
| --- | --- |
| 첫 기록 저장 성공 / Live Activity 시작 성공 / 실제 잠금화면 확인 또는 위젯 설치 | 저장·시스템 시작·실제 사용을 구분. 시작 성공을 실제 시청으로 계산하지 않음 |
| 앱 밖 완료 수·비중, 완료 이후 오류·되돌림 | 앱을 덜 열어도 할 일을 끝내는 가치 확인 |
| 의미 있는 사용일·반복 사용·미리알림 연결 유지 | 앱 실행 수만으로 재방문 가치를 판단하지 않음 |
| 의도하지 않은 표시 변경·기록 전용 메모 노출·사진 저장 실패 | 핵심 신뢰성 개선 확인 |
| 선택한 항목의 실제 표시 성공·수용량 초과·재선택 조작 | 중요한 일이 밀리는 미해결 범위를 감추지 않음 |
| 구매 복원 실패·권리 손실·환불·지원 문의 | 기존 구매자 보호 |
| 사용자당 광고 실수익 + Pro 순수익, 전환·해지 | 광고 차단과 앱 밖 사용 증가를 같은 기간의 실수익과 함께 평가 |

광고 감소분을 무료 핵심 제한이나 기존 Pro 혜택 축소로 보상하지 않는다. 노출 재개는 안전한 구간 분류가 검증된 뒤 별도 판단하며, 이번 빌드의 수익 감소 가능성을 출시 결정에 명시한다.
