# Live Activity 및 위젯 직접 테스트

> 후속 수정: 위젯 설치 상태·확인 메시지의 한국어 표시 및 새로고침 단축어 성공을 확인했다. 아래 내용은 수정 전 기록이다. [수정 기록](../settings-fix-report-2026-10-08.md) 참조.

- 환경: 별도 iPhone 17 Pro Max / iOS 26.1 시뮬레이터.
- 판정: 기본 시작·표시·추가·완료·공유 데이터 반영 정상. 새로고침 단축어 실패는 shortcuts.md 참조.
- 저장 구성을 적용하여 Live Activity 시작. 설정 화면에서 활성, 약 8시간 남음, 할 일 1개 표시 확인.
- 시뮬레이터 실제 잠금화면에서 달력 + `QA settings todo` 카드 확인.
- 실시간 현황 허용 후 잠금화면 할 일 버튼 조작. 화면 즉시 갱신은 지연됐지만 앱 복귀 후 미완료 목록에서 해당 할 일이 사라져 완료 반영 확인.
- 위젯 설치 전 설치 미확인 표시. 위젯을 추가했어요 버튼을 누르면 찾을 수 없다는 안내가 나타나며 설치 상태를 성공으로 표시하지 않음.
- 홈 화면 편집 → 위젯 추가 → LockTodoNote 검색 → 중간 크기 위젯 설치 성공.
- 설치 후 앱의 위젯 확인 버튼으로 `Widget installed` 표시 확인.
- 홈 위젯 + 버튼 → 앱 빠른 추가 편집 화면 → `QA widget todo` 저장. 실제 홈 위젯에 표시 확인.
- 홈 위젯 체크 버튼으로 완료 후 앱 미완료 목록에서 사라짐 확인.
- 단축어로 추가한 메모와 할 일 3개가 실제 홈 위젯에 반영됨.
- 홈 화면 Dynamic Island에서 할 일 개수 및 메모 개수 표시 관찰. 모든 표시 모드/상호작용은 미검증.
- 한국어 설정에서도 위젯 설치 상태·실패 안내 일부가 영어로 표시됨.
- 미검증: 실제 iPhone, 8시간 만료, 시스템에 의한 강제 종료/재시작, 잠금화면 위젯, Dynamic Island 펼침 동작.
