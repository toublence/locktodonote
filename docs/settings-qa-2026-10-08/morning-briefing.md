# 아침 브리핑 직접 테스트

- 환경: 별도 iPhone 17 Pro Max / iOS 26.1 시뮬레이터.
- 판정: 알림 활성화·시각 변경·실제 수신·설정 보존 정상.
- 초기 아침/저녁 알림 OFF 확인.
- 아침 알림 ON 시 iOS 알림 권한 요청 표시. 테스트용 시뮬레이터에서 허용.
- ON 이후 기본 오전 8:00 표시.
- 시간 선택기로 오전 9:13으로 변경하고 화면 반영 확인.
- 2026-10-08 오전 9:13에 앱이 백그라운드인 상태에서 실제 알림 배너 수신.
- 제목: 오늘 하루 계획하기. 내용: 오늘의 카드를 설정해 잠금화면에서 바로 확인하세요.
- 저녁 알림 ON 시 오후 9:00 시간 표시, OFF 시 시간 선택기 숨김.
- 앱 종료/재실행 후 아침 ON / 오전 9:13, 저녁 OFF 유지.
- 테스트 종료 시 아침도 OFF로 전환하고 시간 선택기 숨김 확인.
- 실제 구현은 고정 문구의 반복 알림. 할 일 요약 브리핑을 생성하지 않음.
- 미검증: 권한 거절 경로, 실제 저녁 알림 수신, OFF 이후 예약 제거의 시스템 상태, 날짜/시간대 변경.
