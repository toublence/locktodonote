# 저장한 잠금화면 구성 직접 테스트

- 환경: 별도 iPhone 17 Pro Max / iOS 26.1 시뮬레이터, Debug 1.1.4 (14).
- 판정: 아래 기본 동작 정상.
- 빈 이름 저장 시 이름 입력 안내 표시 확인. 이 검사는 초기 서명 제외 빌드에서 수행.
- 정상 서명 빌드에서 `QA Layout` 저장 성공.
- 무료 상태에서 두 번째 구성 저장을 시도하면 Pro 안내 표시. 구매는 실행하지 않음.
- 더 보기 → 현재 구성으로 덮어쓰기 → 이름을 `QA Replaced`로 변경. 목록에 기존 구성 1개만 유지.
- 앱 종료/재실행 후 `QA Replaced` 유지.
- 홈에서 날짜 + 항목 템플릿으로 변경한 후 저장 구성을 적용하면 달력 + 항목 템플릿으로 복원.
- 구성 적용 후 기존 할 일 3개와 메모 2개 유지. 구성 적용을 통한 Live Activity 시작 및 활성 상태 확인.
- 미검증: 사진 포함 구성, 실제 Pro 결제 상태의 여러 구성 저장/전환, 구성 삭제, 파일 손상/저장 실패 복구.
