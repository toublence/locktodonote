# 동기화 및 데이터 직접 테스트

- 환경: 별도 iPhone 17 Pro Max / iOS 26.1 시뮬레이터.
- 판정: 신규 테스트 데이터의 로컬 저장·확장 공유·재실행 보존 정상. 기기 간 동기화 미구현.
- 실제 설정 화면에는 기존 App Group에 카드를 보관하여 업데이트 후 데이터를 유지한다는 안내만 표시됨.
- 단축어로 저장한 할 일/메모의 앱·홈 위젯 반영 확인.
- 잠금화면 및 홈 위젯의 할 일 완료가 앱에 반영됨.
- 앱 종료 후 초기화 인자 없이 재실행. 미완료 할 일 3개, 메모 2개 유지.
- 저장 구성 `QA Replaced`, 아침 알림 ON 및 오전 9:13 설정 유지 확인.
- 저장 구성을 적용해도 기존 할 일/메모가 유지됨.
- 기기 간/iCloud 동기화 조작 기능은 해당 화면과 확인한 구현에 없음.
- 미검증: 실제 기존 Flutter 설치 데이터 마이그레이션, 앱 업데이트 전후 데이터 보존, 데이터 손상·쓰기 실패·동시 쓰기 복구.
- 기존 사용자 앱 데이터를 삭제하거나 초기화하지 않았으며, 모든 테스트 데이터는 별도 QA 시뮬레이터에 있음.
