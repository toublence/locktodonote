## 확인한 문제

- 단축어 앱의 제공 단축어 이름이 `shortcuts.add.shortTitle`, `shortcuts.refresh.shortTitle`로 표시됨.
- Live Activity 활성 상태에서 새로고침 단축어 실행 시 잠금화면을 새로고칠 수 없다는 실패 메시지. 기존 Live Activity 활성 상태는 이후 앱에서 유지 확인. 원인 미확정.
- 한국어 앱 설정에서도 위젯 설치 상태·일부 안내가 영어로 표시됨.
- 아침 브리핑은 할 일 요약 생성 기능이 아닌 고정 문구 알림이며, 동기화 및 데이터 화면은 보존 안내만 제공. 기대 기능과 구분 필요.
