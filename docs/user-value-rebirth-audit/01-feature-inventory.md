# LockTodoNote 기능별 사용자 가치 평가

2026년 10월 30일. **기능 목록과 직접 사용 범위를 함께 기록한 평가다.** 직접 사용 완료 기능과 소스에서만 찾은 기능을 분리한다. `직접`은 1.2.0 시뮬레이터에서 확인한 범위이며, `소스`는 동작 성공이나 편의성을 검증했다는 뜻이 아니다. 모든 하위 기능이 직접 검증된 것은 아니며, 확인하지 않은 항목은 소스·화면 확인으로 남겼다.

필요성은 대상 사용자에게 필요한 정도다. 낮은 빈도만으로 제거를 권하지 않는다. 사용 경험 칸은 기대 동작과 편의성을, 실제 가치 칸은 기본 기능 대비 차이를 함께 평가한다. 정체성의 기준은 ‘지금 필요한 내용을 앱을 열지 않고 확인하고 행동하게 하는가’다. U16~U43는 [추가 실사용 기록](/Users/nam/projects/ios/locktodonote/docs/user-value-rebirth-audit/06-continuation-evidence.md)에, U01~U15는 [증거 기록](/Users/nam/projects/ios/locktodonote/docs/user-value-rebirth-audit/05-evidence-and-gaps.md)에 연결된다.

## 판단의 한계

기능 수는 계속 사용할 이유의 수가 아니다. 현재 직접 확인한 가장 강한 효용은 여러 줄 입력, 날짜·반복 인식, 오늘과 내일의 분리다. 잠금화면에서 읽는 효용은 직접 확인했다. 앱 밖에서 완료하는 핵심 효용은 성공 검증이 남아 있다. 이 목록을 ‘모든 기능 실제 테스트 통과’ 목록으로 읽으면 안 된다.
