# LockTodoNote 재사용과 무료 및 Pro 가치

2026년 10월 30일. 직접 확인한 무료·Pro 모의 사용과 현재 소스를 근거로 한 평가다. 앱 밖 완료와 Pro 주요 흐름도 실제로 사용했다. 실제 이용자의 유지율이나 결제 전환 개선을 측정한 보고서는 아니다.

## 어제와 오늘 및 내일의 사용 이유

**다시 필요해지는 정보는 있다.** 직접 작성한 매일 반복 항목 ‘물 마시기’가 다음 날 캘린더에도 나타났고, 오늘의 우유 사기와 내일 오후의 병원 예약이 분리되어 보였다. 하루가 바뀌면 오늘 행동해야 할 내용이 달라진다는 점은 제품의 재사용 기반이다.

그러나 사용자가 매일 앱을 실행해야 한다는 결론은 아니다. 오늘의 목록을 잠금화면에서 보고 행동했다면 목적을 달성한 것이다. 반대로 Live Activity 재시작이나 표시 복구 때문에 앱을 자주 열어야 한다면 실행 수는 늘어도 사용자 가치는 낮을 수 있다.

| 상황 | 내일 생기는 가치 | 유지할 조건 | 현재 근거 |
| --- | --- | --- | --- |
| 매일 반복하는 일 | 새 날짜의 할 일을 재입력 없이 확인 | 완료 상태가 날짜별로 이해되고 표시가 이어져야 함 | 내일 캘린더 표시 직접 확인. 실제 자정 미검증 |
| 내일 날짜로 적어 둔 일 | 적절한 날의 행동으로 전환 | 날짜 변경과 표시 시점이 신뢰 가능해야 함 | 병원 예약의 날짜·시각 분리 직접 확인 |
| 어제 끝내지 못한 일 | 잊힌 일을 다시 처리 | 밀린 항목이 중요한 새 일을 가리지 않아야 함 | 이월은 소스 확인, 실사용 미검증 |
| 준비물·짧은 메모 | 행동 직전에 다시 읽는 지침 | 작성 모드 변경으로 원하는 표시가 사라지지 않아야 함 | 짧은 메모 저장 직접 확인 |
| 기존 미리알림 이용자 | 새 원본 항목을 재입력 없이 표시 | 연결·완료 반영과 갱신 범위를 이해해야 함 | EventKit 테스트 항목 가져오기·앱 완료 후 원본 완료 확인. 개인 자료·iCloud 미검증 |
| 시험·여행 D-Day 이용자 | 남은 날짜가 매일 변함 | 목표일까지 계속 의미 있는 정보여야 함 | D-1 적용 확인. 저장 메모와 카드 미리보기의 불일치 관찰 |
| 바뀌지 않는 메모 하나만 이용 | 같은 내용을 다시 상기 | 반복 노출이 실제 실수를 줄여야 함 | 장기 효용은 사용자 확인 필요 |

새 입력이 없는 날도 반복 할 일·이미 예약한 일·계속 확인할 메모가 있다면 사용할 이유가 있다. 이런 내용이 전혀 없는 사람에게는 매일 사용할 이유를 억지로 만들 필요가 없다. 출석, 빈 알림, 장식 변경을 사용 이유로 대신할 수 없다.

## 며칠 쓰다 멈출 수 있는 이유

첫날에는 ‘보인다’는 새로움이 있지만, 다음 주에는 ‘볼 가치가 있는 것만 보인다’와 ‘계속 손봐야 하지 않는다’가 중요하다. 작성 탭 변경이 표시 변경으로 이어지거나, 확인하려고 들어갔는데 광고와 제안이 이어지면 관리 부담이 이익을 넘어설 수 있다.

직접 본 광고는 초기 잠금 카드 탭 시도와 단축어 복귀 등의 Google 테스트 광고다. 이를 근거로 광고가 모든 사용자에게 과도하다고 일반화하지 않는다. 다만 몇 초의 빠른 기록과 수시 확인을 목적으로 하는 앱에서 전면 광고는 본래 행동을 중단시키는 형식이다. 단순히 광고를 늘려 재방문당 수익을 높이는 방향은 제품 목적과 맞지 않을 가능성이 높다.

## 유지율과 앱 밖 이용의 구분

| 항목 | 의미 | 주의점 |
| --- | --- | --- |
| 앱 실행 D1·D7 | 설치 코호트가 다음 날·7일 후 앱을 여는가 | 잠금화면에서만 성공적으로 쓰는 사람을 놓칠 수 있음 |
| 앱 밖 완료 | Live Activity·홈 위젯 등에서 완료가 실제 저장되는가 | 완료 버튼을 누른 시도와 저장 성공을 구분해야 함 |
| 입력 재사용 | 다른 날에도 새 항목을 추가하거나 반복 항목을 처리하는가 | 테스트·중복 요청과 구분 필요 |
| 설치된 위젯 | 사용할 수 있는 표시 경로가 설정되어 있는가 | 설치되어 있다는 사실이 읽었다는 뜻은 아님 |
| 위젯 새로고침·렌더링 | 시스템이 표시 데이터를 요청했는가 | 사람이 실제로 봤다는 증거로 집계하면 안 됨 |
| 표시 복구를 위한 실행 | 표시 문제를 해결하려고 앱에 들어왔는가 | 자발적인 사용과 달리 마찰일 수 있음 |

이벤트가 소스에 존재하는 것과 신뢰할 수 있는 실제 사용자 데이터가 수집된 것은 다르다. 이번에는 운영 분석 계정에서 D1·D7 또는 앱 밖 완료 수를 조회하지 않았다. 잠금화면을 단순히 읽는 행위는 앱에서 직접 관측하기 어려우므로, 관찰 가능한 행동과 사용자 인터뷰를 함께 보는 편이 적절하다. 메모 내용이나 할 일 본문을 분석 수집의 전제로 삼을 필요는 없다.

기존 [10월 28일 수익 모델](/Users/nam/projects/ios/locktodonote/docs/iap-1000-model-2026-10-28.json)에 있는 1.41%·1.92%·3.28%는 다운로드 후 유료 전환의 전사값이다. **D1·D7 사용 유지율이 아니다.**

## 무료 가치

무료로 직접 경험한 여러 줄 작성, 날짜·시각 인식, 매일 반복과 미래 조회는 쓸모가 있었다. 무료 사용자가 핵심 효용을 한 번 경험할 수 있는 구조는 유지할 가치가 있다. 더 많이 팔기 위해 이 기본 흐름을 다시 잠그는 것은 권하지 않는다.

무료의 한계가 곧 불합리함은 아니다. 단축어를 하루 5회 넘게 쓰거나 업무·개인 구성을 여러 개 저장하는 사용자가 추가 편의를 구매하는 구조는 설명 가능하다. 무료에서 잠금화면·홈 위젯·Dynamic Island의 완료까지 성공했다. 실제 하루가 지난 뒤 표시 유지 여부는 별도 미검증이다.

현재 Pro 화면은 직접 보았을 때 꾸미기 설명이 먼저였고 실용적인 자동화·연동은 혜택 목록 안에 있었다. 일상 문제를 해결하려는 사람에게 ‘매일 다시 입력하거나 설정하는 일을 줄인다’는 결과가 더 잘 전달될 필요가 있다.

D-Day 개인화 미리보기와 목적별 결제 안내를 직접 사용했다. 제목 변경이 카드와 안내에 이어져 결과 이해에 도움이 됐다. 이를 새 기능으로 제안하지 않는다. 반면 연동과 자동 전환은 무료 상태에서 내 자료에 어떻게 적용될지 경험하기 전에 Pro를 요구하는 구조다. 필요한 사람에게는 해당 결과를 이해할 수 있는 체험 방식이 더 중요할 수 있다.

Pro 사진은 적용됐지만 구성 저장 오류를 겪었고, D-Day는 저장 메모와 카드 미리보기의 불일치를 관찰했다. 유료 결과의 신뢰도 문제는 구매 판단을 낮춘다. 현재 나는 바로 구독하지 않겠다.

24시간 앱 내 임시 체험은 템플릿만 허용한다. 이번 결제 화면에 보인 연간 상품의 7일 무료 체험과는 별개다. 화면의 제안만으로 모든 계정에 같은 체험 자격이 있다고 단정하지 않는다. 실제 구매·체험 시작·구매 복원을 하지 않았다.

## 30일 평균 하루 1달러 목표

목표를 ‘연속 30일간 앱의 광고 수익과 IAP 수익금 합계가 최소 $30’으로 해석한다. 서버 비용·환불 등을 차감한 순이익을 목표로 삼으려면 별도 정의가 필요하다. 서로 다른 통화와 기간의 숫자를 섞어 달성 여부를 판단하면 안 된다.

기존 자료에는 선택 기간 수익금 $87, IAP 38건 등이 있지만 기간 시작·종료와 전체 기간 여부가 확인되지 않았다. 따라서 이번 평가에서 ‘이미 하루 $1을 달성했다’거나 월 수익으로 환산할 수 없다. 현재 광고 노출 수, 국가별 eCPM, 실제 30일 수익, Pro 전환과 갱신 자료도 조회하지 않았다.

아래는 **필요 규모를 이해하기 위한 가정**이다. 현재 실적이나 업계 평균이 아니다.

| 광고만으로 하루 $1일 때 가정 eCPM | 필요한 광고 노출 수의 하루 평균 |
| --- | ---: |
| $1 | 1,000회 |
| $3 | 약 334회 |
| $5 | 200회 |

계산식은 `하루 광고 수익 = 하루 유효 노출 수 × eCPM ÷ 1,000`이다. DAU로 바로 바꿀 수는 없다. 잠금화면에서만 이용하면 앱 오픈 광고 기회가 없고, Pro 이용자는 광고 제거 대상이다. 빈도 제한과 광고 채움률도 영향을 준다.

| IAP만으로 30일 $30일 때 가정 건당 수익금 | 해당 30일에 필요한 과금 건수 |
| --- | ---: |
| $1 | 30건 |
| $5 | 6건 |
| $10 | 3건 |

여기서 수익금은 스토어 표시 가격과 다르다. 무료 체험 시작이나 구매 복원을 과금 1건으로 세지 않는다. 연간·평생 구매가 특정 달의 현금 수익을 만들었다고 그 수익이 다음 달에도 반복되는 것은 아니다.

**목표는 작은 편이지만, 현재 구조로 달성할 가능성을 수치로 확정할 근거는 부족하다.** 적은 수의 만족한 유료 사용자가 의미 있는 기여를 할 수는 있다. 광고를 더 보여 주는 것보다, 기존 반복·연동·자동화가 어떤 사람의 매일 작업을 실제로 줄이는지 확인하는 것이 우선이다.
