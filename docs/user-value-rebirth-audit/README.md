# LockTodoNote 사용자 가치와 재탄생 평가

2026년 10월 30일 KST. iPhone 13 mini와 iPhone 17 Pro Max 시뮬레이터에서 **1.2.0 빌드 20을 직접 조작한 평가**다. 신규 온보딩, 무료 작성·완료, 앱 밖 완료, 누적 목록, Pro 모의 권한의 템플릿·반복·자동 전환·미리알림 연결까지 사용했다. 모든 하위 기능의 실사용 전수 검증을 마친 것은 아니다. 실기기·시간 경과·거래 관련 미검증 범위는 별도 기록했다.

**핵심 가치는 실제로 있다. 오늘의 소수 할 일을 자주 잊는 사람에게 유용한 보조 도구다.** 잠금화면 Live Activity·홈 위젯·Dynamic Island에서 앱을 열지 않고 완료하는 데 성공했다. 다만 모든 할 일을 옮길 주력 관리 앱이나 즉시 구독할 앱으로는 설득력이 부족하다. 기록이 늘면 무엇을 보여줄지 관리해야 하고, 초기 설정과 일부 유료 결과에 마찰이 있었다.

앱 코드·UI·데이터 구조는 수정하지 않았다. 기존 설치 바이너리를 사용했고 현재 소스로 재빌드하지 않았다. 실제 구매·체험 결제·배포는 하지 않았다. Pro는 새 테스트 설치본에서 기존 DEBUG 권한으로만 사용한 뒤 정상 무료 실행으로 돌렸다. 기존 개인 자료와 구매 권리는 변경하지 않았다.

## 가장 가치 있는 기능 TOP 5

| 순위 | 기능 | 왜 필요한가 | 직접 확인 |
| --- | --- | --- | --- |
| 1 | 앱 밖 확인·완료 | 앱을 다시 열지 않아도 잊은 일을 보고 처리 | Live Activity·홈 위젯·Dynamic Island에서 완료, 앱 목록 반영 |
| 2 | 빠른 작성과 날짜·반복 인식 | 생각났을 때 기록하고 수동 날짜 선택을 줄임 | 한국어 3줄 저장·내일 오후 3시 인식·단축어로 실제 추가 |
| 3 | 반복 할 일 | 새 입력 없는 날에도 다시 필요한 정보를 준비 | 매일 항목의 내일 미리보기·매 3일 규칙 저장. 실제 날짜 경과는 미검증 |
| 4 | Apple 미리알림 연결 | 이미 쓰는 목록을 이중 입력하지 않음 | EventKit 테스트 항목 가져오기·앱 완료 후 원본 완료 확인 |
| 5 | 상황별 표시 항목과 자동 전환 | 많은 일 중 현재 필요한 일만 보게 함 | 13개 미완료 중 업무용 2개만 카드에 표시. 백그라운드 시각 전환은 미검증 |

짧은 메모·날짜 조회는 이 경험을 보완한다. 사진·D-Day는 취향과 목표 기간에 따라 가치가 있지만 모든 사용자의 지속 구독 이유로 보기는 어렵다.

## 앱을 삭제하게 만들 수 있는 이유 TOP 5

실제 이탈 통계가 아닌 관찰에 근거한 제품 위험이다.

| 순위 | 이유 | 사용자에게 생기는 문제 |
| --- | --- | --- |
| 1 | 최신 항목이 중요한 항목을 밀어냄 | 12개 누적 시 카드 최대 5개에 오래된 일이 빠짐. 살펴본 편집창에서 우선순위·순서 지정은 발견하지 못함 |
| 2 | 작성 모드가 표시 내용도 바꿈 | 메모를 쓰려다 할 일이 카드에서 사라졌다고 느낄 수 있음. 실제 기록 삭제는 아님 |
| 3 | 짧은 진입에 광고와 제안이 이어짐 | 단축어 사용 뒤 복귀 등에서 테스트 전면 광고·알림 제안으로 흐름 중단. 운영 빈도는 미확인 |
| 4 | 단순한 목적에 비해 설정할 것이 많음 | 구성 선저장→규칙→표시 항목, 위젯 설치·단축어 배치를 따로 이해해야 함 |
| 5 | 기본 앱으로 충분한 사용자에게 관리 비용이 추가됨 | 표시의 편익보다 새 앱·표시 상태를 관리하는 일이 커질 수 있음. 일정 수정 경로도 찾기 어려웠음 |

별도의 결과 불일치도 기록했다. D-Day 편집에는 저장된 메모가 카드 미리보기에는 없다고 표시됐고, 선택 사진을 구성으로 저장할 때 읽기 오류가 났다. 원인을 분석하거나 수정하지 않았다. 디스크 부족과 화면 자동화 문제는 제품 결함으로 세지 않았다.

## 설치와 지불의 이유

설치 이유는 **‘적어 둬도 다시 열어 보지 않는 오늘의 소수 할 일을, 휴대폰을 사용할 때 보고 바로 끝내고 싶다’**다. 기존 미리알림 이용자에게는 대체 앱보다 표시와 행동을 보완하는 도구가 더 자연스럽다.

[Apple 공식 안내](https://support.apple.com/en-euro/guide/iphone/iphcd5c65ccf/26/ios/26)도 기본 미리알림 위젯의 완료를 지원한다고 설명한다. 완료 버튼 하나가 독점 차별점은 아니다. 큰 카드·짧은 메모·상황별 표시의 조합이 필요한 사람에게 집중해야 한다. 기본 앱과 같은 조건으로 나란히 비교하는 실험은 하지 않았다.

무료에서도 작성부터 앱 밖 완료까지 핵심 가치를 경험했다. Pro의 가장 설득력 있는 지속 가치는 재입력을 줄이는 미리알림 연결, 고급 반복, 수동 변경을 줄이는 자동 전환이다. 직접 본 개인화 미리보기와 목적별 결제 안내는 결과를 이해하는 데 도움이 됐다. 반면 일반 Pro 화면은 꾸미기가 먼저였고, 사진 구성 저장과 D-Day 메모 표시에서는 신뢰를 떨어뜨리는 결과가 있었다. 지금 즉시 구독하지는 않겠다.

30일 평균 하루 $1은 합계 $30이다. 실제 30일 수익·광고 노출·전환·갱신 자료가 없어 달성을 확정할 수 없다. 기존 선택 기간의 $87을 월 수익으로 환산하지 않았다. 앱 밖에서 성공적으로 쓰면 앱 오픈 광고 기회가 줄어든다는 점까지 수익 평가에 반영했다.

## 최종 사용자 평가

**내가 계속 사용할 것인가?** 오늘 할 일을 자주 잊는 상황이라면 소수 항목을 위한 보조 도구로 계속 써 보겠다. 전체 기록을 옮기거나 바로 구독하지는 않겠다.

**기존 미리알림 대신 쓸 이유가 있는가?** 모든 사용자에게 충분하지는 않다. 큰 카드와 메모·상황별 표시를 원하는 사람에게는 이유가 있다. 기존 목록을 유지하고 연결하는 방향이 더 설득력 있다.

**하루가 지나도 다시 필요한가?** 반복 항목과 미리 적은 일정이 있다면 그렇다. 매일 앱을 열 필요는 없다. 다만 실제 자정·장기 백그라운드 갱신과 D1·D7 유지율은 이번 결과로 보장하지 않는다.

**재탄생 가능성이 있는가?** 있다. 기능 추가보다 ‘지금 중요한 것이 계속 보이고, 설정을 자주 손보지 않으며, 보이는 결과를 믿을 수 있는 경험’에 집중할 가치가 있다.
