# 기존 기능과 무료 Pro 및 광고 정책

> 재검토 반영 · 기존 디자인 유지가 우선이다. 이 문서는 원안 기록이며, 충돌하는 개발 범위·화면·정책은 [최소 변경 설계](/Users/nam/projects/ios/locktodonote/docs/user-value-rebirth-audit/rebirth-design/06-revised-minimal-design.md)로 대체한다. ‘먼저 표시 3개’·화면 재배치·새 공통 작성창·전역 적용·기본 정렬 변경은 확정 개발 대상에서 제외했다.

## 기존 기능별 처리

사용 빈도가 낮아도 가독성·개인정보·복원처럼 매일의 신뢰를 지탱하는 기능은 유지한다. 제거 검토는 기록·구매 권리 삭제를 뜻하지 않는다.

## 무료와 Pro 구성

가격·상품 종류는 이번에 변경하지 않는다. 기존 구매자는 구매 당시의 기능과 광고 제거 권리를 유지한다. 업그레이드로 기존 사용자 자료·Pro 설정을 삭제하지 않는다.

| 사용자 목적 | 무료 | Pro | 제공 이유 |
| --- | --- | --- | --- |
| 기록하고 오늘 보기 | 기존 할 일·메모·여러 줄·자연어 인식 | 동일 | 설치의 핵심 목적 |
| 먼저 표시·기본 순서·완료·취소 | 모두 제공 | 동일 | 중요한 일이 안 보이는 것을 결제 이유로 삼지 않음 |
| 앱 밖 보기·완료·기존 위젯·Island | 기존 지원 범위 유지 | 동일 + 기존 템플릿 차이 | 핵심 가치 완결 |
| 기본 반복·미래 조회·이월 | 기존 무료 범위 유지 | 동일 | 내일의 사용 이유 |
| 기본 달력/메모 표시·현재 1개 구성 | 기존 범위 유지 | 기존 여러 구성 | 무료 경계를 몰래 확대·축소하지 않음 |
| 혼합·날짜·사진·D-Day·색상 | 기존 체험과 개인화 미리보기 | 기존 적용 권한 유지 | 생활 목적과 취향의 추가 편의 |
| 가독성·프라이버시·언어 | 기존 무료 범위 유지 | 동일 | 안전하게 읽고 이해할 기본 조건 |
| 고급 반복 | 기존 안내·규칙 선택 미리보기 | 기존 4종 사용 | 반복 계산 절약 |
| 미리알림 연결 | 샘플 결과와 범위 설명. 개인 데이터 접근 없음 | 기존 목록 선택·연결·원본 완료 | 이중 입력 절약 |
| 시간별 전환 | 샘플 결과와 설명 | 기존 규칙·여러 구성·개별 범위 | 반복 수동 전환 절약 |
| 단축어 추가 | 기존 하루 5회 | 기존 무제한 | 많이 쓰는 사람의 추가 편의. 초과해도 앱 내 작성은 가능 |
| 광고 | 핵심 흐름은 0회 | 기존 광고 제거 유지 | 결제 강요 없이 기본 행동 보호 |

‘먼저 표시’는 모든 템플릿을 무료로 바꾸는 정책이 아니다. 무료가 혼합 결과를 고르면 기존 유료 경계가 적용된다. 무료 메모 저장은 항상 가능하며 기존 할 일 표시를 바꾸지 않는다.

### 만료와 복원

Pro 만료·체험 종료 시 현재 entitlement 처리 규칙을 기준으로 확인하고, 바뀔 표시와 중단될 연결·자동화를 안내한다. 제안 기준은 자동 전환을 중지하고 보존된 무료 기본 표시로 돌아가는 것이다. 기존 사진·규칙·구성·기록을 지우지 않는다. 다시 구매하거나 복원하면 보존된 설정을 선택할 수 있어야 한다.

미리알림의 기존 연결 만료 처리·가져온 복사본 정리와 새 표시 선택 정리가 충돌하지 않아야 한다. 미리알림 원본은 수정·삭제하지 않는다. 진행 중인 원본 완료의 성공 여부를 만료를 이유로 숨기지 않는다. 관련 완료를 확정할 수 없으면 원본 확인을 안내한다. 만료 처리 개선이 필요하면 P1의 권리/상태 설계로 한정한다.

24시간 템플릿 체험 종료는 전체 Pro 만료와 구분한다. 초안은 보존하고 무료 표시로 복귀한다. StoreKit 체험은 실제 자격과 조건을 표시한다. 복원은 구매 1건이나 수익 1건으로 집계하지 않는다.

## 광고 정책

### P0 기본 정책

**재탄생 P0에서는 앱 오픈 전면 광고를 노출하지 않는다.** 현재 조사에서 확인한 형식은 앱 오픈 광고다. 핵심 진입 대부분이 작성·확인·완료 또는 표시 복구와 연결되고, 출처를 확실히 구분하지 못하는 상태에서 최소 간격만 조정해도 흐름을 보호하기 어렵다. 광고 SDK 제거·구매 권리 변경까지 이 결정에 포함하지 않는다.

| 흐름 | 광고 허용 | 부가 안내 |
| --- | --- | --- |
| 첫 실행·첫 입력·첫 표시 | 금지 | Pro·알림·단축어 연속 팝업 금지 |
| 앱 아이콘·알림으로 오늘 확인 | 금지 | 광고 로딩을 기다린 뒤 목록을 보여주지 않음 |
| 작성 시작·저장·편집·완료·취소 | 금지 | 완료 직후 알림 제안·결제 화면 자동 표시 금지 |
| Live Activity·홈/잠금 위젯·Island·단축어·공유·딥링크·Siri 복귀 | 금지 | 출처가 불명확하면 핵심 진입으로 취급 |
| 허용 설정·사진 선택·원본 앱에서 복귀 | 금지 | 외부 앱 이동을 새 광고 세션으로 오인하지 않음 |
| 표시 복구·연결 실패·저장 경고·원본 완료 재시도 | 금지 | 오류 해결을 결제 조건으로 만들지 않음 |
| 구매·복원·결제 취소 | 금지 | 취소 뒤 광고로 돌아서 강요하지 않음 |
| 앱 밖 표시 면 | 금지 | 체크 영역 옆 광고·로고형 광고·구매 유도 금지 |
| 템플릿 탐색·과거 조회·설정 | P0 금지 | 광고 재개 여부는 별도 근거로 판단 |

### 이후 판단

앱 밖 사용이 늘면 앱 실행 광고가 줄어드는 것은 자연스럽다. 수익 감소를 숨기지 않고 광고 수익·IAP 실수익·앱 밖 완료를 같은 기간에 나란히 비교한다. 광고 중단으로 손실이 생겨도 먼저 고장 없이 쓰는 사람과 Pro의 실용 수요를 확인한다.

P2에서 수익이 부족하고 핵심 행동 보호가 검증된 경우에만, 사용자가 자발적으로 오래 탐색하는 꾸미기 화면의 비차단 광고를 별도 검토한다. 이는 새 광고 형식 개발이므로 기존 기능으로 수익 목표를 만족하면 만들지 않는다. 조건부 검토가 광고 도입 결정은 아니다.

검토 시 기본 조건은 화면 하단 명확한 광고 구분, 입력·주 동작과 분리, 레이아웃 이동/자동 재생/강제 대기 없음, Pro 제외, 기기 내 광고 설정 준수다. 출처 판정 실패·충돌·완료 실패가 있으면 광고를 표시하지 않는 쪽을 기본값으로 한다. 전면 광고를 수익 부족만으로 핵심 흐름에 복구하지 않는다.
